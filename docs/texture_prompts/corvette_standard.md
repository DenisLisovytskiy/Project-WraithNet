## Prompt

```

Beamier hull than a light corvette: fuller superstructure, a 76mm-class deck gun forward, a CIWS mount aft, a larger VLS farm amidships, two mast radars. Still a corvette, not a destroyer and not a carrier. Clean waterline for a transparent sprite.

Paint: hostile dark iron, rust-red decks, copper-orange rim. No hull numbers, no flags, no text.

Camera: elevated three-quarter bow view, about 35–40 degrees down. Orthographic / long lens. Isolated on a fully transparent background.

Lighting: cool moonlight, PBR naval game asset.

Square 1024x1024, PNG, transparent background, ship filling about 85% of the frame, bow up.
```
