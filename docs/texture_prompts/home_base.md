# Texture prompt — home base

WraithNet `home_base`: friendly RTB / landing pad. Drawn today as a green flag on a disc. One shared airfield per scenario, not a carrier.

## Prompt

```
Game-ready concept render of a tiny fictional forward airbase, single installation only, centered in frame.

Compact land airstrip: short concrete pad, one small hangar, a control tower with a teal-green windsock / flag panel (no nationality), fuel bladders, taxi-line chevrons. Friendly, orderly, not ruined. Scale is a pocket FOB, not an international airport.

Paint: pale concrete, olive-teal friendly livery on the hangar doors and flag (around a sea-green RGB 90,200,140). No tail numbers, no real flags, no parked fighter jets (aircraft are separate entities).

Camera: elevated three-quarter view, about 40 degrees down, pad centered. Orthographic / long lens. Isolated on a fully transparent background.

Lighting: cool moonlight, cyan edge on the runway, PBR military game asset.

Square 1024x1024, PNG, transparent background, subject filling about 80% of the frame.
```

## Negative prompt

```
carrier deck, city airport, airliners, parked F-35, people, US flag, other national flags, text, “NATO”, explosions, cartoon, sky gradient, watermark
```

## Output spec

- 1024×1024 PNG, transparent
- Friendly teal-green, not hostile red
- No aircraft on the pad
