# Texture prompt — EW jammer

WraithNet electronic-warfare jammer (static hexagon glyph, purple `(170, 90, 220)`, plus a jam-radius disc). Not a target type in the strike catalog; it blinds comms, it does not shoot.

## Prompt

```
Game-ready concept render of a fictional electronic-warfare jammer site, single installation only, centered in frame.

Hexagonal gravel pad with a lattice mast covered in dipole arrays, a folding planar jammer antenna, and a small generator shelter. Looks like an antenna farm, not a radar truck and not a SAM. Cables, insulators, a few purple-tinted warning beacons on the mast (no readable text).

Paint: dark graphite structure with violet-purple dielectric panels (around RGB 170,90,220). Subtle glow in the antenna faces, not neon sci-fi. No flags, no “EW” lettering, no dishes that look like satellite TV.

Camera: elevated three-quarter view, about 40 degrees down, hexagonal pad readable from above. Orthographic / long lens. Isolated on a fully transparent background.

Lighting: cool moonlight, magenta-violet rim on the mast, PBR military game asset.

Square 1024x1024, PNG, transparent background, subject filling about 80% of the frame.
```

## Negative prompt

```
SAM launcher, bunker, radar truck with a huge dish, cell tower photo, people, national flag, text, numbers, sci-fi energy beam, lightning, cartoon, sky, watermark
```

## Output spec

- 1024×1024 PNG, transparent
- Hexagonal pad + mast (this replaces the hexagon glyph)
- No weapons
